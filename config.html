Events

Pre Tool Change

G-code commands executed before each tool change (M6). E.g. turn off coolant, open ATC cover.

Post Tool Change

G-code commands executed after each tool change (M6) completes. E.g. close ATC cover, restore coolant.

Pre TLS

G-code commands executed right before the tool-length probe starts, after the spindle is parked over the toolsetter at the seek start Z. Use it to activate a wired toolsetter (e.g. M64 P1), open a shroud, or dwell before probing.

Post TLS

G-code commands executed immediately after the tool-length probe completes but before the TLO is written back. Use it to deactivate the toolsetter (e.g. M65 P1), close a shroud, or turn off dust collection.

Abort Event

Additional g-code fired on abort (e.g. close ATC cover, stop spindle) after the built-in clamp command. The clamp is always sent first as a safety no matter what you type here — leave this empty if you don't need anything extra.

Advanced

Air Pressure, Drawbar Sensor and Tool Seated Sensor are live. Tool Holder is still a preview. Each sensor is read with M66 at its own point in the sequence — pressure before the tool change starts and after every drawbar release, the drawbar sensor right after the collet unclamps, the tool-seated sensor right after it clamps. A fault on any of them pauses the job with a dialog instead of moving on. Tool Holder is recorded here but nothing reads it yet.

Air Pressure Sensor

grblHAL aux input the pressure switch is wired to. The list is read from the controller, so it only offers inputs this board actually has. Pick N/A if you don't have one. Pressure is read as OK when the input is LOW (same wiring convention Sienci's macros assume) — invert the port in firmware ($370) if your switch reads the other way round. Checked once before the tool change starts, and again after each drawbar release: a fault pauses the job with a dialog offering Re-check or Abort.

Drawbar Sensor

grblHAL aux input reporting the drawbar's released state at the spindle. Read as released when the input is HIGH — invert the port in firmware ($370) if wired the other way round. Read right after the collet unclamps — a fault pauses the job with a dialog offering Re-check or Abort, same as Air Pressure. Independent of the Tool Seated sensor below; point both at the same pin if your kit uses one physical sensor for both.

Tool Seated Sensor

grblHAL aux input reporting whether the tool is seated in the spindle. Read as seated when the input is HIGH — invert the port in firmware ($370) if wired the other way round. Read right after the collet clamps — a fault pauses the job with a dialog offering Re-check or Abort, same as Air Pressure. Independent of the Drawbar sensor above; point both at the same pin if your kit uses one physical sensor for both.
