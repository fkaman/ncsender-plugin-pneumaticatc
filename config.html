Automatic Release/Clamp

Tap Release or Clamp to fire it right away. Hold for 1 second to arm a countdown, so you have time to walk to the spindle first.

Events

Pre Tool Change

G-code commands executed before each tool change (M6). E.g. turn off coolant, open ATC cover.

Post Tool Change

G-code commands executed after each tool change (M6) completes. E.g. close ATC cover, restore coolant.

Abort Event

G-code commands executed when a tool change is aborted (e.g. close ATC cover, stop spindle). The clamp aux command is prepended automatically for safety, so a released drawbar doesn't drop a bit when you cancel mid-swap.
