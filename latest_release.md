## Beta: tools by Tool ID

Needs ncSender Pro 2.0.239-beta.1 or newer (beta channel).

- A tool number (T) now means the Tool ID from your Tool Library, not the slot. M6 T20 loads Tool 20 from whichever slot the library puts it in.
- A tool with no slot in the library is loaded by hand.
- A tool number that is not in the library still means that slot, as long as the slot is not holding another tool.
